# Orbital Architect 0.1.0

First public release for Minecraft Java 1.21.1 and NeoForge 21.1.265 or later in the 21.1 series.

- Plan domes, 4×4 airlocks, corridors and cable galleries with a 3D preview.
- Build in Survival using FE-powered drones, connected storage and tier upgrades. Drones return with a 20% battery reserve and recharge to 100% before taking off again.
- Manage completed rooms with a map, teleportation, selective repairs and material replacement orders.
- Link supply terminals to monitor energy and materials. Applied Energistics 2 integration is optional.
